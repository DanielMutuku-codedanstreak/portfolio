About Me

I’m a software engineer based in Nairobi, Kenya. I hold a Bachelor of Science in Software Engineering from Murang'a University of Technology (Second Class Upper, GPA: 3.47). Over the past few years, my primary focus has been mobile development—specifically architecting cross-platform Flutter applications that interface with physical IoT hardware (like EV charging stations) and fintech payment systems.

When building client applications, I pay close attention to real-world edge cases: spotty mobile networks, offline-first caching, predictable state management, and clear API boundaries with backend teammates.

Before focusing full-time on software engineering, I spent considerable time doing graphic design and vector branding—designing school flags, emblems, and visual identities. That background gave me an appreciation for spacing, typography, and visual hierarchy that directly informs how I build clean, responsive user interfaces today.

Mobile Application • CleanTech & IoT Geviton Limited

SafiCharge — EV Charging Mobile App

A production cross-platform mobile application built for electric vehicle drivers in Kenya. It lets users find nearby charging stations, check live charger availability, monitor active charging sessions, and pay automatically via M-Pesa.

  • Built station discovery mapping with real-time availability filters using flutter_map and latlong2.
  • Engineered the live charging session screen displaying real-time telemetry (State of Charge, power draw rate, and cost).
  • Implemented the automated M-Pesa billing checkout flow with instant transaction callbacks.
  • Integrated offline-first caching via dio_cache_interceptor_file_store to handle patchy network connectivity, with Sentry for error tracking.
  • Collaborated with our backend engineer's Go microservices consuming OCPP (Open Charge Point Protocol) hardware sockets.
